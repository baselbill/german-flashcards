# Karteikarten — German Flashcards

A beautiful, typographically refined flashcard application for learning German vocabulary and phrases.

## Features

- Clean, paper-like interface with refined typography
- Progress tracking and streak visualization
- Spaced repetition for effective learning
- Responsive design for desktop and mobile
- Local storage of study data

## Usage

Simply open `index.html` in your web browser to start learning.

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Begin your German learning journey
